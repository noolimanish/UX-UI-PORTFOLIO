# MANISH NOOLI // THE CINEMATICS OF DIGITAL INTERACTION

A high-craft, cinematic UI/UX and product architecture portfolio showcasing the design engineering, spring dynamics, and cognitive systems of **Manish Nooli**.

---

## 🎬 Cinematic Direction & Aesthetics

- **Color Grading**: Replaced arcade neon tones with prestige cinematic film stock grades:
  - **Kodak 35mm Gold**: Roger Deakins-inspired warm tungsten, organic 35mm grain, and golden hour anamorphic flares.
  - **Blade Runner 2049**: High-contrast atmospheric chiaroscuro with deep teal oceanic shadows and sharp amber flares.
  - **Dune Monolith**: Sun-bleached titanium, desert bronze, and brutalist mineral tones.
  - **IMAX 70mm Monochrome**: Ultra-fine silver gelatin emulsion with deep black voids.
- **Cinematographic Aspect Ratios**: Interactive letterbox mattes toggling between **2.39:1 Panavision Cinemascope**, **16:9 Director's Cut**, and **1.43:1 Full Bleed**.
- **Film Slate & Timecode**: Real-time 24.000 FPS running timecode (`HH:MM:SS:FF`) with camera status indicator.
- **Dynamic 60 FPS Projector Canvas**: HTML5 Canvas rendering dust motes, anamorphic horizontal flare streaks responding to cursor coordinates, and light beam cones.
- **Cinematic Web Audio Synthesizer**: Native Web Audio synthesizer generating deep Hans Zimmer sub-bass Braams, 35mm projector clicks, and anamorphic bell shimmers without external MP3 dependencies.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5174`.

### 3. Build for Production
```bash
npm run build
```
